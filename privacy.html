ミラメイク(MiraMake)

プライバシーポリシー

Ryota Masuda(以下「運営者」)は、iOSアプリ「ミラメイク」(英語名 MiraMake。以下「本アプリ」)におけるお客様の情報の取り扱いを、次のとおり定めます。

English version of this Privacy Policy / 本隱私權政策的繁體中文版

顔写真は端末の外に出ません
顔の分析はすべてお使いのiPhoneの中で行います。外へ出るのは、お客様が「AIに聞く」を押したときに送る19項目の差の数値と顔タイプの名前だけで、顔写真は送りません。前の版にあった「プロ添削の事前予約」は取り下げました。写真をサーバーへ送る経路は、いまのアプリにはありません。

1. 取得する情報

本アプリの顔分析は、お使いのiPhoneの中で完結します。分析のために撮影した写真が外部に送信されることはありません。

運営者がサーバーで受け取るのは、お客様が「AIに聞く」を押したときに限られ、内容は次のとおりです。

  • 診断の合計点(0〜100)
  • 顔の19項目それぞれについて、項目の名前、いまと目標の特徴の呼び名、差の数値
  • 顔タイプの名前と、その説明文
  • アドバイスを書く言語(日本語・英語・繁体字中国語のいずれか)

顔写真は送りません。氏名・メールアドレス・電話番号・端末を識別するIDも送らないため、届いた数値が特定の個人に結び付くことはありません。アカウント登録もありません。

2. 顔データの取り扱い

本条は、顔データについて取得・利用・開示・共有・保存期間をまとめて定めるものです。

2.1 取得する顔データ

  • お客様がiPhoneの標準の前面カメラで撮影した、またはフォトライブラリから選んだ顔写真
  • お客様が「なりたい顔」として登録した写真
  • これらの写真から端末内で計算する数値: 顔の特徴量(512次元のベクトル)、顔の106点の位置座標、そこから求めた19個の比率、8種類の顔タイプ分類

本アプリは TrueDepth カメラ、ARKit の顔トラッキング、深度データ、Face ID を一切使用しません。顔データを本人確認・個人の識別・認証に使うことはなく、他人の顔と照合する顔認識も行いません。

2.2 利用目的

  • お客様自身が登録した「なりたい顔」との近さを点数で示すこと
  • 顔の部位ごとの違いをマップで示し、メイクの練習に役立てていただくこと

これらの計算はすべてお使いのiPhoneの中で行います。分析のために顔写真や上記の数値を外部へ送信することはありません。

2.3 第三者への提供・共有

  • 顔データを第三者へ販売・提供・共有することはありません
  • 広告配信、マーケティング、プロファイリング、および運営者または第三者の機械学習モデルの学習に顔データを使用することはありません
  • 「AIに聞く」で送る数値は、文章を書かせるために Google LLC の Gemini API へ渡します。顔写真は渡しません。Google は不正利用の監視のため、送信内容を55日間保持します(Gemini API のログ方針)

2.4 保存場所

  • 端末内: 顔写真と分析結果は本アプリ専用の保存領域に暗号化して保存し(端末のロック中は復号できない設定)、iCloudバックアップの対象から除外しています。本アプリを削除すると顔データも消えます
  • サーバー: 顔写真を保存する経路はありません。「AIに聞く」で送る数値は、アドバイスの文章を作るために処理するだけで、運営者のサーバーには保存しません

2.5 保存期間と削除

  • 端末内: お客様が削除するか本アプリを削除するまで保存します。ダイアリーの記録は無料会員では7日で自動削除します(Plus会員は削除されるまで保持)。読んだAIメイクアドバイスの本文も、その記録と同じ期間で消えます
  • サーバー: 顔データを保存しません
  • 端末内の顔データは、アプリの設定画面からお客様ご自身でいつでも消去できます(第6条)

3. 利用目的(顔データ以外を含む全体)

  • お客様が「AIに聞く」を押したときに、メイクのアドバイスを書くこと
  • そのアドバイスに添える短い動画を探すこと(YouTube Data API へ渡すのは検索語だけです)
  • 1日あたりの生成回数を数え、運営の費用が上限を超えないようにすること

広告配信や第三者へのデータ販売には使用しません。行動トラッキングも行いません。

4. 保存先と保存期間

  • 保存先: 顔データは保存しません。アドバイスの通信は Supabase の Edge Function(運営会社 Supabase, Inc.(米国))を経由します
  • 保存期間: 端末内の保存は第2.5条のとおりです。サーバーに残るのは、1日あたりの生成回数の合計と、動画の検索結果の控えだけで、どちらも個人には結び付きません

5. 第三者提供・委託

  • 取得した情報を第三者に販売・提供することはありません
  • アドバイスの生成は Google LLC(Gemini API)へ、動画の検索は Google LLC(YouTube Data API)へ委託します。どちらにも顔写真は渡しません
  • 通信の中継とクラウド基盤の利用は Supabase, Inc. への委託にあたります。同社は運営者の指示に基づく処理のみを行い、同社の目的でデータを利用することはありません

6. 削除のご依頼・お問い合わせ

端末内の顔データと診断の記録は、本アプリの設定画面から、またはアプリを削除することで、お客様ご自身がいつでも消去できます。運営者のサーバーにお客様の顔データは残らないため、削除のご依頼は不要です。

7. 課金情報

ミラメイク Plus(サブスクリプション)およびApp内課金の決済はAppleが行い、運営者はクレジットカード情報等を取得しません。

8. カメラ・通知の利用

  • カメラ: 顔の撮影と分析のために使用します。撮影した写真は端末内に保存されます(サーバーへ送られるのは第2.4条の予約時のみ)
  • 通知: メイクリマインドのための端末内通知(ローカル通知)です。外部サーバーを経由しません

9. 安全管理

サーバーへの通信は暗号化(HTTPS)しています。サーバー上の写真は非公開領域に保存し、アプリからの読み出しができない権限設定にしています。端末内の顔写真は端末のロック中は復号できない保護区分で保存します。

10. 改定

本ポリシーを改定するときは、本ページで公表します。重要な変更はアプリ内でもお知らせします。
