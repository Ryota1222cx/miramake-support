MiraMake

隱私權政策

增田稜太（以下稱「本方」或「營運者」）就iOS應用程式MiraMake（日文名稱：ミラメイク，以下稱「本應用程式」）如何處理您的資訊，說明如下。

本頁為繁體中文版。日文版請見此處。若內容有出入，以日文版為準。

臉部照片不會離開您的裝置
臉部分析全部在您的 iPhone 內進行。唯一會傳出的，只有您按下「問 AI」時送出的19項差異數值與臉型名稱，照片不會送出。舊版本中的「專家妝容點評預約」已經取下，目前的 App 沒有任何會上傳照片的路徑。

1. 本方蒐集的資訊

本 App 的臉部分析在您的 iPhone 內完成。為了分析而拍攝的照片不會被傳送到外部。

營運者在伺服器端接收到的資料，僅限於您按下「問 AI」時送出的內容：

  • 分析的總分（0〜100）
  • 19 項測量中每一項的名稱、目前與目標特徵的說法，以及差距的數值
  • 臉型的名稱與說明文字
  • 撰寫建議所使用的語言（日文、英文或繁體中文其中一種）

照片不會送出。姓名、電子郵件、電話號碼與裝置識別碼也都不會送出，因此收到的數值無法連結到特定個人。本 App 也不需要註冊帳號。

2. 臉部資料

本條集中說明臉部資料的蒐集、使用、揭露、共用、儲存、保存與刪除。

2.1 本方蒐集的臉部資料

  • 您以iPhone標準前置鏡頭拍攝，或從相片圖庫選取的臉部照片。
  • 您登錄為「理想臉孔」的照片。
  • 在您的裝置上由這些照片計算出的數值：臉部特徵向量（512維）、106個臉部特徵點的座標、由這些點導出的19項幾何比例，以及8分類的臉型標籤。

本應用程式不使用TrueDepth相機、ARKit臉部追蹤、深度資料或Face ID。本方絕不會將臉部資料用於識別、驗證或認證身分，也絕不會將您的臉與他人的臉進行比對（不進行人臉辨識）。

2.2 臉部資料的使用方式

  • 顯示您的臉與您自行登錄的理想臉孔之間的相似度分數。
  • 依部位顯示差異圖，供您練習化妝。

上述所有運算皆在您的iPhone上執行。您的臉部照片與第2.1條所列的數值，都不會為了分析而被傳送至任何地方。

2.3 對第三方的揭露與共用

  • 我們不會將臉部資料販售、提供或分享給第三方
  • 我們不會將臉部資料用於廣告投放、行銷、剖析，也不會用於訓練本方或第三方的機器學習模型
  • 您按下「問 AI」時送出的數值，會傳給 Google LLC 的 Gemini API 以撰寫文章，照片不會傳送。Google 為了監控濫用，會保留送出的內容 55 天（Gemini API 記錄政策）

2.4 臉部資料的儲存地點

  • 裝置內：臉部照片與分析結果會加密儲存在本 App 專用的儲存區（裝置鎖定時無法解密的設定），並排除在 iCloud 備份之外。刪除本 App 時，臉部資料也會一併刪除。
  • 伺服器：沒有任何會儲存臉部照片的路徑。您按下「問 AI」時送出的數值，只會用於撰寫建議，不會儲存在營運者的伺服器上。

2.5 臉部資料的保存與刪除

  • 裝置內：保存到您自行刪除或刪除本 App 為止。日記的紀錄在免費會員為 7 天後自動刪除（Plus 會員會保存到您刪除為止）。您讀過的 AI 妝容建議，也會與所屬紀錄同時間刪除。
  • 伺服器：我們不儲存臉部資料。
  • 裝置內的臉部資料，您可以隨時從 App 的設定畫面自行刪除（第 6 條）。

3. 使用目的（包含臉部資料以外的所有資料）

  • 在您按下「問 AI」時撰寫妝容建議
  • 尋找隨建議附上的短片（傳給 YouTube Data API 的只有搜尋關鍵字）
  • 計算每日的產生次數，讓營運成本不超過上限

我們不會用於廣告投放或販售資料給第三方，也不會進行行為追蹤。

4. 儲存地點與保存期間

  • 儲存地點：我們不儲存臉部資料。建議的通訊會經由 Supabase 的 Edge Function（營運公司為美國的 Supabase, Inc.）。
  • 保存期間：裝置內的保存如第 2.5 條所述。留在伺服器上的只有每日產生次數的合計，以及影片搜尋結果的暫存，兩者都無法連結到特定個人。

5. 對第三方的揭露與委外處理

  • 我們不會將取得的資訊販售或提供給第三方
  • 建議的產生委託給 Google LLC（Gemini API），影片的搜尋委託給 Google LLC（YouTube Data API）。兩者都不會收到臉部照片。
  • 通訊的中繼與雲端基礎架構委託給 Supabase, Inc.，該公司僅依營運者的指示處理資料，不會用於自身目的。

6. 刪除請求與聯絡方式

裝置內的臉部資料與分析紀錄，您可以隨時從本 App 的設定畫面，或藉由刪除本 App 自行清除。營運者的伺服器上不會留下您的臉部資料，因此不需要提出刪除請求。

7. 付款資訊

MiraMake Plus（訂閱）與應用程式內購買的付款由Apple處理。本方不會收到您的信用卡資訊。

8. 相機與通知

  • 相機：用於拍攝並分析您的臉部照片。照片儲存在您的裝置上（僅在第2.4條所述的預約情形下才會傳送至本方伺服器）
  • 通知：化妝提醒為在您裝置上產生的本機通知，不會經過任何外部伺服器。

9. 安全性

與本方伺服器之間的通訊以HTTPS加密。伺服器上的照片存放在私有儲存區，其存取政策不允許本應用程式讀回。裝置上的臉部照片以裝置鎖定期間無法解密的保護等級儲存。

10. 本政策的變更

本方修訂本政策時，會在本頁公布修訂內容。重大變更亦會在本應用程式內通知您。
