<h2>1. 取得する情報</h2>
<p>本アプリの顔分析は、お使いのiPhoneの中で完結します。分析のために撮影した写真が外部に送信されることはありません。</p>
<p>運営者がサーバーで受け取るのは、お客様が「AIに聞く」を押したときに限られ、内容は次のとおりです。</p>
<ul>
  <li>診断の合計点(0〜100)</li>
  <li>顔の11項目それぞれについて、項目の名前、いまと目標の特徴の呼び名、差の数値</li>
  <li>顔立ちを表す3つのことば(求心と遠心・子供顔と大人顔・直線的と曲線的)</li>
  <li>アドバイスを書く言語(日本語・英語・繁体字中国語のいずれか)</li>
</ul>
<p>顔写真は送りません。氏名・メールアドレス・電話番号・端末を識別するIDも送らないため、届いた数値が特定の個人に結び付くことはありません。アカウント登録もありません。</p>

<h2>2. 顔データの取り扱い</h2>
<p>本条は、顔データについて取得・利用・開示・共有・保存期間をまとめて定めるものです。</p>

<h3>2.1 取得する顔データ</h3>
<ul>
  <li>お客様がiPhoneの標準の前面カメラで撮影した、またはフォトライブラリから選んだ顔写真</li>
  <li>お客様が「なりたい顔」として登録した写真</li>
  <li>これらの写真から端末内で計算する数値: 顔の特徴量(512次元のベクトル)、顔の106点の位置座標、そこから求めた19個の比率</li>
</ul>
<p>本アプリは TrueDepth カメラ、ARKit の顔トラッキング、深度データ、Face ID を一切使用しません。顔データを本人確認・個人の識別・認証に使うことはなく、他人の顔と照合する顔認識も行いません。</p>

<h3>2.2 利用目的</h3>
<ul>
  <li>お客様自身が登録した「なりたい顔」との近さを点数で示すこと</li>
  <li>顔の部位ごとの違いをマップで示し、メイクの練習に役立てていただくこと</li>
</ul>
<p>これらの計算はすべてお使いのiPhoneの中で行います。分析のために顔写真や上記の数値を外部へ送信することはありません。</p>

<h3>2.3 第三者への提供・共有</h3>
<ul>
  <li>顔データを第三者へ販売・提供・共有することはありません</li>
  <li>広告配信、マーケティング、プロファイリング、および運営者または第三者の機械学習モデルの学習に顔データを使用することはありません</li>
  <li>「AIに聞く」で送る数値は、文章を書かせるために Google LLC の Gemini API へ渡します。顔写真は渡しません。Google は不正利用の監視のため、送信内容を55日間保持します(<a href="https://ai.google.dev/gemini-api/docs/logs-policy">Gemini API のログ方針</a>)</li>
</ul>

<h3>2.4 保存場所</h3>
<ul>
  <li>端末内: 顔写真と分析結果は本アプリ専用の保存領域に暗号化して保存し(端末のロック中は復号できない設定)、iCloudバックアップの対象から除外しています。本アプリを削除すると顔データも消えます</li>
  <li>サーバー: 顔写真を保存する経路はありません。「AIに聞く」で送る数値は、アドバイスの文章を作るために処理するだけで、運営者のサーバーには保存しません</li>
</ul>

<h3>2.5 保存期間と削除</h3>
<ul>
  <li>端末内: お客様が削除するか本アプリを削除するまで保存します。ダイアリーの記録は無料会員では7日で自動削除します(Plus会員は削除されるまで保持)。Plusをやめたあとは30日の猶予を置き、その間は記録も写真も消しません。読んだAIメイクアドバイスの本文も、その記録と同じ期間で消えます</li>
  <li>サーバー: 顔データを保存しません</li>
  <li>端末内の顔データは、アプリの設定画面からお客様ご自身でいつでも消去できます(第6条)</li>
</ul>

<h2>3. 利用目的(顔データ以外を含む全体)</h2>
<ul>
  <li>お客様が「AIに聞く」を押したときに、メイクのアドバイスを書くこと</li>

</ul>
